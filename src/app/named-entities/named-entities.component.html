Named Entity Levels

Peptidoform Names

A peptidoform name (single >) describes the specific molecular form of a peptide, including its modifications. This is the most specific level of naming. 

// Named peptidoform
const seq = Sequence.fromProforma("(>TMT-labeled peptide)PEPTIDEK");

console.log(seq.peptidoformName); // "TMT-labeled peptide"
console.log(seq.toStrippedString()); // "PEPTIDEK"

// With modifications
const seq2 = Sequence.fromProforma("(>Phospho-peptide)PEPS[Phospho]T");
console.log(seq2.peptidoformName); // "Phospho-peptide"

Use case: Identifying specific peptide variants in proteomics experiments.

Peptidoform Ion Names

A peptidoform ion name (double >>) describes the ion form of a peptidoform, typically including charge state information. This level is useful for mass spectrometry data. 

// Named peptidoform ion
const seq = Sequence.fromProforma("(>>Precursor z=2)PEPTIDEK/2");

console.log(seq.peptidoformIonName); // "Precursor z=2"
console.log(seq.charge); // 2

// Multiple charges with name
const seq2 = Sequence.fromProforma("(>>Doubly charged)PEPTIDE/2");
console.log(seq2.peptidoformIonName); // "Doubly charged"
console.log(seq2.charge); // 2

Use case: Annotating MS/MS precursor ions with descriptive names.

Compound Ion Names

A compound ion name (triple >>>) describes a collection of peptidoform ions, typically used for chimeric spectra or MS1-level annotations. 

// Named compound ion
const seq = Sequence.fromProforma("(>>>Chimeric Spectrum 1234)PEPTIDEK/2");

console.log(seq.compoundIonName); // "Chimeric Spectrum 1234"

// Chimeric spectrum with compound name
const chimeric = Sequence.fromProforma(
  "(>>>MS2 Scan 5678)PEPTIDE/2+ANOTHER/3"
);
console.log(chimeric.compoundIonName); // "MS2 Scan 5678"
console.log(chimeric.isChimeric); // true

Use case: Annotating chimeric MS2 spectra with scan or spectrum identifiers.

Combining All Naming Levels

All three naming levels can be combined to provide complete hierarchical annotation of peptide ions. The order is always compound ion (>>>) → peptidoform ion (>>) → peptidoform (>). 

// All three levels combined
const seq = Sequence.fromProforma(
  "(>>>Chimeric Spectrum 1234)(>>Precursor z=2)(>Phospho-peptide)PEPS[Phospho]T/2"
);

console.log(seq.compoundIonName); // "Chimeric Spectrum 1234"
console.log(seq.peptidoformIonName); // "Precursor z=2"
console.log(seq.peptidoformName); // "Phospho-peptide"
console.log(seq.charge); // 2
console.log(seq.toStrippedString()); // "PEPSST"

// Hierarchy: Compound > Ion > Peptidoform
// (>>>Level 1)(>>Level 2)(>Level 3)SEQUENCE

Use case: Complete annotation of complex MS data with multiple identification levels.
