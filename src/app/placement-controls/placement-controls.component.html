Placement Control Types

Position Constraint

The Position control restricts where a modification can occur within the sequence. This is useful for isobaric tags that should only be placed at specific positions (e.g., only at positions M or C). 

// TMT6plex only at positions M or C, applied to K residues
const seq = Sequence.fromProforma("<[TMT6plex|Position:M,C]@K>MTPEILTCNSIGCLKG");

const globalMod = seq.globalMods[0];
console.log(globalMod.positionConstraint); // ["M", "C"]
console.log(globalMod.targetResidues); // ["K"]

// This means: K residues can be modified, but only when they appear at positions M or C

Use case: Isobaric tags that have specific positional requirements for labeling efficiency.

Limit Per Position

The Limit control specifies the maximum number of modifications that can occur at any given position. This is useful for representing partial oxidation or other variable modifications. 

// Maximum of 2 oxidations on methionine residues
const seq = Sequence.fromProforma("<[Oxidation|Limit:2]@M>MMMMMMMM");

const globalMod = seq.globalMods[0];
console.log(globalMod.limitPerPosition); // 2

// This means: Only 2 of the 8 M residues can have oxidation modifications

Use case: Variable modifications where not all sites are modified (e.g., partial oxidation, phosphorylation).

Colocalize with Known Peptidoforms (CoMKP)

CoMKP indicates that the modification should colocalize with known peptidoforms. This means the modification must occur at the same positions in different peptidoforms when they are known. 

// Phosphorylation that colocalizes with known peptidoforms
const seq = Sequence.fromProforma("<[Phospho|CoMKP]@S,T,Y>STYPEPTIDE");

const globalMod = seq.globalMods[0];
console.log(globalMod.colocalizeKnown); // true

// This means: Phosphorylation sites should be consistent across known isoforms

Use case: Ensuring modification consistency across characterized peptidoforms.

Colocalize with Unknown Peptidoforms (CoMUP)

CoMUP indicates that the modification should colocalize with unknown peptidoforms. This is used when the modification pattern is expected to be consistent even when specific sites are not yet characterized. 

// Oxidation that colocalizes with unknown peptidoforms
const seq = Sequence.fromProforma("<[Oxidation|CoMUP]@M>MMMPEPTIDE");

const globalMod = seq.globalMods[0];
console.log(globalMod.colocalizeUnknown); // true

// This means: Oxidation pattern should be consistent even for uncharacterized sites

Use case: Representing modification patterns that are consistent but not fully characterized.

Combined Placement Controls

Multiple placement controls can be combined to create complex modification rules. All controls are specified using pipe (|) separators within the same global modification. 

// Combination of Position, Limit, and CoMKP
const seq = Sequence.fromProforma(
  "<[TMT6plex|Position:M,C|Limit:1|CoMKP]@K,N-term>MTPEILTCNSIGCLKG"
);

const globalMod = seq.globalMods[0];
console.log(globalMod.modValue.primaryValue); // "TMT6plex"
console.log(globalMod.positionConstraint); // ["M", "C"]
console.log(globalMod.limitPerPosition); // 1
console.log(globalMod.colocalizeKnown); // true
console.log(globalMod.targetResidues); // ["K", {type: "terminal", terminal: "N-term"}]

// This means:
// - TMT6plex can modify K and N-terminus
// - But only at positions M or C
// - Maximum 1 modification per position
// - Must be consistent with known peptidoforms

Use case: Complex isobaric labeling experiments with specific requirements.
