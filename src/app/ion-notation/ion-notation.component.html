Ion Notation in SequalJS (ProForma 2.1)

ProForma 2.1 introduces ion notation for fragment ions, allowing you to specify the type of fragment ion represented by a sequence. This is particularly useful in mass spectrometry for indicating b-type, y-type, a-type, c-type, and other fragment ions.

C-Terminal Ion Notation

C-terminal ion notation indicates that the sequence represents a fragment ion ending at the C-terminus. Common C-terminal ions include b-type, a-type, and c-type ions. 

// b-type ion (most common in CID/HCD)
const seq = Sequence.fromProforma("PEPTIDE-[b-type-ion]");

// Accessing the ion information
const cTermMods = seq.mods.get(-2);
console.log(cTermMods[0].isIonType); // true
console.log(cTermMods[0].modValue.primaryValue); // "b-type-ion"

N-Terminal Ion Notation

N-terminal ion notation indicates that the sequence represents a fragment ion starting from the N-terminus. Common N-terminal representations for reverse ions like y, x, and z types. 

// a-type ion
const seq = Sequence.fromProforma("[a-type-ion]-PEPTIDE");

const nTermMods = seq.mods.get(-1);
console.log(nTermMods[0].isIonType); // true
console.log(nTermMods[0].modValue.primaryValue); // "a-type-ion"

Ion Notation with Modifications

Ion notation can be combined with other modifications to represent fragment ions with post-translational modifications. 

// Fragment ion with phosphorylation
const seq = Sequence.fromProforma("[a-type-ion]-PEPS[Phospho]TIDE-[b-type-ion]");

// Access both ion notation and modifications
const nTermMods = seq.mods.get(-1);
const cTermMods = seq.mods.get(-2);
const phosphoSite = seq.seq[3]; // S with Phospho

console.log(nTermMods[0].isIonType); // true
console.log(cTermMods[0].isIonType); // true
console.log(phosphoSite.mods[0].modValue.primaryValue); // "Phospho"
