Ion Notation in SequalJS (ProForma 2.1)

ProForma 2.1 introduces ion notation for fragment ions, allowing you to specify the type of fragment ion represented by a sequence. Ion type annotations are C-terminal modifications only, appearing at the end of the sequence. This is particularly useful in mass spectrometry for indicating b-type, y-type, a-type, c-type, z-type, and other fragment ions.

Ion Notation (C-Terminal Only)

Ion type notation in ProForma 2.1 is always placed at the C-terminal (end of sequence). All ion types (b, y, a, c, x, z) are indicated using C-terminal modification syntax. 

// b-type ion (most common in CID/HCD)
const seq = Sequence.fromProforma("PEPTIDE-[b-type-ion]");

// Accessing the ion information
const cTermMods = seq.mods.get(-2);
console.log(cTermMods[0].isIonType); // true
console.log(cTermMods[0].modValue.primaryValue); // "b-type-ion"

// y-type ion
const seq2 = Sequence.fromProforma("PEPTIDE-[y-type-ion]");
console.log(seq2.toProforma()); // "PEPTIDE-[y-type-ion]"

Ion Notation with PTMs

Ion notation can be combined with other modifications to represent fragment ions with post-translational modifications. 

// Fragment ion with phosphorylation
const seq = Sequence.fromProforma("PEPS[Phospho]TIDE-[b-type-ion]");

// Access both ion notation and modifications
const cTermMods = seq.mods.get(-2);
const phosphoSite = seq.seq[3]; // S with Phospho

console.log(cTermMods[0].isIonType); // true
console.log(cTermMods[0].modValue.primaryValue); // "b-type-ion"
console.log(phosphoSite.mods[0].modValue.primaryValue); // "Phospho"

Ion Notation with Charge State

Ion notation can be combined with charge state information for precursor or fragment ions. 

// y-type ion with charge state 2
const seq = Sequence.fromProforma("PEPTIDE-[y-type-ion]/2");

console.log('Charge:', seq.charge); // 2

const cTermMods = seq.mods.get(-2);
console.log(cTermMods[0].isIonType); // true
console.log(cTermMods[0].modValue.primaryValue); // "y-type-ion"

console.log(seq.toProforma()); // "PEPTIDE-[y-type-ion]/2"
